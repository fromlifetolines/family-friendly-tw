# 親子友善台灣 Family-Friendly Taiwan

一個協助家長尋找台灣親子友善空間的互動式網站，提供地點搜尋、設施篩選、地圖與清單切換，以及場館聯絡與導航資訊。

## 🌟 特色功能

- 🗺️ 地圖與清單切換；只使用來源座標或唯一匹配官方門牌座標的地點
- 🔎 搜尋景點、車站、地址與設施，並依縣市、場所類型及親子設施篩選
- 📍 使用裝置定位並依距離排序附近地點（需允許瀏覽器存取位置及有來源座標的地點）
- 🍼 收錄臺北市親子館、哺集乳室、親子友善廁所及官方兒童遊戲場；呈現來源列出的設施數量
- ☎️ 地點資訊提供導航、電話撥打與官方網站連結（若有資料）

## 📊 資料範圍

目前收錄臺北市政府來源提供的 13 間親子館、合併 10 筆完全重複列後的 516 間哺集乳室、393 處親子友善廁所，以及 520 個官方兒童遊戲場座標點。親子友善廁所來源 metadata 宣告 350 筆、下載 CSV 實際 393 筆，網站保留 CSV 實際紀錄並揭露差異；兒童遊戲場來源 972 列中有 452 列完全重複，去重後保留 520 個不同座標。親子館及哺集乳室只有在行政區和門牌唯一匹配臺北市官方門牌座標時才顯示地圖標記。其他設施未由來源明確確認時保持未知。

政府資料開放平臺用於查找及核對政府資料集，座標採用臺北市門牌資料唯一匹配，或使用公園路燈工程管理處提供的兒童遊戲場座標。其他縣市、百貨、交通場站、博物館、科學館、醫療院所及親子餐廳尚待逐筆取得可靠來源，不會以示意或假資料填補。

來源與欄位處理規則見 [資料來源與查核政策](./DATA_SOURCES.md)。

## 💻 本地開發

### 安裝相依套件

```bash
npm install
```

### 啟動開發伺服器

```bash
npm run dev
```

開啟瀏覽器訪問 `http://localhost:5173/family-friendly-tw/`

### 建置專案

```bash
npm run build
```

建置後的檔案會產生在 `dist` 資料夾中。

### 預覽建置結果

```bash
npm run preview
```

## 📝 自動部署

`npm run sync:data` 會同步親子館、哺集乳室、親子友善廁所與官方門牌資料；`npm run validate:data` 可單獨檢查資料。建置時也會自動執行資料驗證。本專案使用 GitHub Actions 將 Vite 的 `dist` 目錄部署到 GitHub Pages。每次推送到 `main` 分支時會自動部署。
